# Site vitrine — Gilles Solignac

Site vitrine statique et responsive de Gilles Solignac, Directeur Commercial externalisé à Joué-lès-Tours, réalisé selon la charte graphique Bras Droit des Dirigeants.

## Fichiers
- `index.html` — contenu, structure et portrait optimisé intégré
- `styles.css` — identité visuelle et responsive
- `script.js` — menu mobile, animations et démonstration du formulaire

## Déploiement
Le site est statique et peut être déployé directement sur Vercel sans étape de build.
